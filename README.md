# 🔐 securehesh vault

## 📝 Project Description
SecureHesh Vault is a lightweight Ethereum-based smart contract designed for users to safely store and withdraw ETH on-chain. It implements essential vault functionalities with minimal complexity while maintaining security and transparency.

## 🌍 Project Vision
To create a secure, open-source vault system that empowers users to manage their digital assets without relying on centralized intermediaries. The goal is to serve as a foundation for more advanced decentralized financial tools.

## ⭐ Key Features
- **Secure Deposits:** Users can deposit ETH into their personal vault balance.
- **Safe Withdrawals:** Only the owner of funds can withdraw stored ETH.
- **On-chain Balance Tracking:** Transparent and immutable balance records.
- **Event Logging:** Deposit and withdrawal events for external tracking.

## 🚀 Future Scope
- Multi-token support (ERC-20 & ERC-721).
- Role-based access and multi-signature withdrawals.
- Time-locked vault functionality.
- Integration with decentralized identity (DID) systems.
- Web3 dashboard for enhanced user interaction.
